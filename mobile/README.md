# MOE Members (phone app)

The native iOS and Android app for members of Makers and Engineers @Oberlin. Built with Expo SDK 57, React Native and Expo Router. It is a real native app, not a web view.

## How it works

- Members sign in on the device with their portal email and password (`src/lib/supabase.ts`). The session is kept in the device keychain.
- The app calls the club website with the member's access token (`src/lib/api.ts`).
  - Reads: `GET /api/mobile/*` in the site (`app/api/mobile/`). These call the same loaders as the web portal pages.
  - Writes: the same `/api/member/*` routes the web portal uses.
- Screens live in `src/app/`. Tabs: Home, Projects, Teams, Directory, More. The team workspace (notes and photos per teammate) is `src/app/(tabs)/teams/[projectId].tsx`.

A new member feature needs its site endpoint deployed and a matching screen here.

## Run it

```bash
npm install
npx expo run:ios      # or: npx expo run:android (needs Android Studio)
```

Point a development build at a local site with `EXPO_PUBLIC_API_URL=http://localhost:3108 npx expo start`. Without it the app talks to https://oberlin32engineeringsociety.com.

`ios/` and `android/` are generated by `npx expo prebuild`. Do not edit or commit them.

## Updating the app without a store release

JavaScript, screens and images ship over the air with EAS Update (`expo-updates` is installed). One time setup, by the club's Expo account owner:

```bash
npx eas-cli@latest login
npx eas-cli@latest init
npx eas-cli@latest update:configure
```

Then `npx eas-cli@latest update --channel production` publishes a new version to installed apps. A store release is only needed when native code changes (a new native module or Expo SDK).

## Store builds

`npx eas-cli@latest build -p ios` and `-p android`, then `eas submit`. This needs an Apple Developer account and a Google Play developer account owned by the club.
